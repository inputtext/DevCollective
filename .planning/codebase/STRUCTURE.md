## Entry Points & Execution Paths

| Context | Entry Point | Invocation Command | Description |
|---------|-------------|--------------------|-------------|
| **Development** | `dev.ts` | `npm run dev` | Runs `tsx dev.ts`, booting Express with Vite middleware on port 3000 |
| **Production App** | `app-start.ts` | `npm start` | Runs bundled `dist/app-start.cjs` serving static assets and API |
| **Production WS** | `ws-start.ts` | `npm run start:ws` | Runs bundled `dist/ws-start.cjs` listening on Render `PORT` |
| **Build** | `vite.config.ts` | `npm run build` | Builds client SPA to `dist/` and compiles server scripts via `esbuild` |
| **Python AI Service** | `ai-service/main.py` | `uvicorn main:app` | FastAPI embedding service on port 8000 |
