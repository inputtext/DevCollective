## Infrastructure & Configuration

### Environment Variables Matrix

| Variable | Target | Required | Description |
|----------|--------|----------|-------------|
| `PORT` | App & WS | Yes | HTTP/WS listening port (defaults: 3000 app, 3001 ws) |
| `NODE_ENV` | All | Yes | Runtime environment (`development` vs `production`) |
| `APP_URL` | App | Yes in Prod | Canonical application URL (`https://devcollective-app.onrender.com`) |
| `VITE_CLERK_PUBLISHABLE_KEY` | Client | Yes | Clerk publishable key exposed to frontend |
| `CLERK_PUBLISHABLE_KEY` | Server | Yes | Clerk publishable key on server |
| `CLERK_SECRET_KEY` | Server & WS | Yes | Secret key for Clerk token verification & user fetch |
| `CLERK_AUTHORIZED_PARTIES` | Server & WS | Yes in Prod | Origin allowlist for JWT verification |
| `VITE_SUPABASE_URL` / `SUPABASE_URL` | Client / Server | Yes | Supabase project URL |
| `VITE_SUPABASE_PUBLISHABLE_KEY` | Client | Yes | Supabase anon key for public browser client |
| `SUPABASE_SECRET_KEY` | Server & WS | Yes | Supabase service role key (bypass RLS for server ops) |
| `VITE_WS_URL` | Client | Yes | WebSocket connection URL (`wss://...` or `ws://localhost:3001/ws`) |
| `GEMINI_API_KEY` | Server | Yes | Google Gemini API key for AI features |
| `COLLEGE_EMAIL_DOMAIN` | Server | Optional | Target college email domain (default: `ghrietn.raisoni.net`) |
| `ADMIN_EMAILS` | Server | Optional | Comma-separated list of platform administrators |
| `RESEND_API_KEY` | Server | Optional | Transactional email dispatch key |
