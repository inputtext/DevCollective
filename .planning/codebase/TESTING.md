## Existing Quality Gates

### 1. TypeScript Compilation Gate
Running `npm run lint` performs strict type checking without emitting output files:
```powershell
npm run lint
```

### 2. Full Production Bundle Gate
Running `npm run build` verifies both client and server compilations:
```powershell
npm run build
```
This ensures:
- Vite successfully compiles all React TSX pages, CSS modules, and public assets into `dist/`.
- `esbuild` successfully compiles all server entrypoints:
  - `dist/server.cjs`
  - `dist/dev.cjs`
  - `dist/app-start.cjs`
  - `dist/start.cjs`
  - `dist/ws-start.cjs`

### 3. Service Health Endpoints
- App API: `GET http://localhost:3000/api/health` -> `{"status":"ok","timestamp":"..."}`
- WebSocket Server: `GET http://localhost:3001/health` -> `{"status":"ok"}`
