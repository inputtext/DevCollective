## Detailed Findings

### 1. Dual Supabase Access Patterns
- **Finding**: While `server.ts`, `server/supabase.ts`, and `server/websocket.ts` use the official `@supabase/supabase-js` client (`supabaseAdmin`), `server/learningProgress.ts` manually constructs raw HTTP requests using `fetch` with REST headers (`apikey`, `Authorization: Bearer ...`).
- **Risk**: Changes to Supabase authentication or headers might require updating two disparate patterns; error handling differs between SDK exceptions and fetch response parsing.
- **Resolution**: Refactor `learningProgress.ts` to use `supabaseAdmin.from(...)` and `supabaseAdmin.rpc(...)`.

### 2. Real-Time WebSocket Scaling
- **Finding**: In `server/websocket.ts`, user presence (`presence = new Map()`) and active connections (`clients = new Set()`) are stored entirely in process memory.
- **Risk**: Works flawlessly for single-instance deployments (such as Render's single Web Service). If horizontal scaling or auto-scaling is enabled, messages between users connected to different instances will not cross over without a message broker.
- **Resolution**: Plan for Redis pub/sub integration (`ioredis`) when horizontal scaling is required.

### 3. Test Automation Gap
- **Finding**: `package.json` contains `"lint": "tsc --noEmit"` and build scripts, but no test runner (`test` script is absent).
- **Risk**: Functional regressions in gamification (REP calculations, streak updates), permissions, and chat handling must be manually caught.
- **Resolution**: Introduce `vitest` for fast TypeScript unit testing.

### 4. Heavy Local AI Embeddings (`ai-service/`)
- **Finding**: `ai-service/main.py` downloads and initializes `BAAI/bge-m3`, a comprehensive multilingual embedding model with 1024 output dimensions.
- **Risk**: Requires substantial memory and CPU on cold-start. Running this locally on constrained laptops or budget cloud tiers may cause OOM errors.
- **Resolution**: Provide an option to fall back to Gemini's `text-embedding-004` API or mock embeddings during lightweight local development.
